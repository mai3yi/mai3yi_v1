Hazard Panel

Interactive Light System · 2025

Overview

Hazard Panel is a proximity-driven alert system that translates distance and manual input into escalating visual and audio states. The project examines the contrast between disrupting peace to see what happens and leaving it alone and experiencing nothing.

Interaction

User distance determines the system’s baseline state, progressing from calm to alert as proximity increases. A physical button triggers a lockdown override that blares loudly on a buzzer and latches for a fixed duration, removing user control once activated.

Technical Implementation

  • Ultrasonic sensor maps proximity to discrete logic states
  • Non-blocking timing via millis() enables concurrent LED, audio, and state changes
  • Arduino handles input and timing; TouchDesigner manages visual logic and compositing

Constraints

No text-based feedback is provided. Color, rhythm, and intensity are the sole communication methods, prioritizing instinctive interpretation over clarity.
